# TurboFlow 足球盘口产品需求文档 v4.7

版本：v4.7
对象：足球传统盘口 — 单场预测与冠军晋级信息架构升级
基线：v4.4《TurboFlow 足球盘口产品需求文档》
状态：当前评审稿

> 本文是 v4.4 的增量。v4.4 已经定义平台报价型足球传统盘口、赛事级下注对象、冠军/晋级/赛季结果/系列赛预测、多笔单注、不可串关、二次确认、我的注单和 Design Board 覆盖规则。v4.7 不改变交易模型，不引入 CLOB，也不恢复 v4.5 整届赛事预测大赛；本次只重构“冠军与晋级”的信息架构、页面路径和 mock 展示。

## 一、本期要解决的问题

v4.4 的冠军与晋级入口已经把长期盘从单场比赛里拆出来，但首页结构仍偏“赛事卡片 + 进入详情”基础版，存在三个问题：

- 用户进入“冠军与晋级”后，第一层看到的是赛事对象，但卡片没有充分说明该对象内部有哪些预测。
- 世界杯、欧冠、英超这类对象内部的预测层级不同，不能在全局层面混排“小组赛、8 强、冠军、欧冠资格”等维度。
- Design Board 和 mock 需要更明确地展示“产品大类 → 系列赛/赛季对象 → 对象内预测”的路径，避免设计师把冠军与晋级误做成全局市场流。

v4.7 的目标是把信息架构固定为：

```text
足球
├─ 单场预测
│  └─ 近期比赛结果和比赛内容盘口
└─ 冠军与晋级
   └─ 不同系列赛 / 赛季对象
      └─ 该对象内部的不同预测
```

## 二、本期范围

### 2.1 本期做什么

| 范围 | 说明 |
|------|------|
| 一级入口命名 | 首页 tab 从“比赛”升级为“单场预测”，与“冠军与晋级”并列 |
| 冠军与晋级首页 | 只展示系列赛、杯赛或赛季对象，不全局混排所有预测 |
| 系列赛详情页 | 进入对象后再按小组赛、淘汰赛、冠军、晋级、赛季结果、系列赛等组展示预测 |
| World Cup mock | 新增 `世界杯 2026` 样例，覆盖小组赛、淘汰赛、冠军三类内部预测 |
| 市场覆盖 | 当前 mock 覆盖 11 个赛事级市场，Design Board 必须动态读取并全量展示 |
| 盘口分类 | `出线`、`进入8强`、`进入决赛` 等标题归入晋级类盘口 |
| Design Board | 同步展示冠军与晋级首页、系列赛详情页、对象内分组和全量市场矩阵 |

### 2.2 本期不做什么

| 不做项 | 说明 |
|--------|------|
| 不恢复 v4.5 预测大赛 | 小组赛填表、淘汰赛 bracket、冠亚季殿军完整预测仍隐藏 |
| 不做 CLOB / Yes-No 订单簿 | Polymarket / Kalshi 的市场发现方式可借鉴，但交易模型仍是平台欧洲赔率 |
| 不做赛事级串关 | 冠军、晋级、赛季结果之间相关性强，第一版仍只支持多笔单注 |
| 不做球员奖项 | 金靴、助攻王、MVP 等仍是 P2 扩展 |
| 不做全局阶段导航 | “小组赛 / 8 强 / 冠军”不能放在冠军与晋级全局层，只能出现在具体系列赛对象内部 |

## 三、信息架构

### 3.1 一级入口

| 入口 | 内容 | 说明 |
|------|------|------|
| 单场预测 | 近期单场比赛结果和比赛内容 | 胜平负、让球、大小球、波胆、总进球数、开球权等 |
| 冠军与晋级 | 系列赛、杯赛、赛季级结果 | 世界杯、欧冠、英超等对象内部的长期预测 |

用户从首页先选择“单场预测”或“冠军与晋级”。两者都是足球产品的一部分，共用投注单、赔率格式、我的注单和二次确认，但判断对象不同。

### 3.2 冠军与晋级首页

冠军与晋级首页不直接展示所有市场，而是展示不同系列赛或赛季对象：

```text
冠军与晋级
先选择系列赛或赛季，再查看该对象内部的小组赛、淘汰赛、冠军等预测。

┌ 世界杯 2026 ─────────────────────┐
│ 国际 · 杯赛系列赛                 │
│ 小组出线、淘汰赛晋级和最终冠军预测 │
│ 小组第一 / 小组出线 / 进入8强 / 冠军 │
│ 5 个预测                           │
└──────────────────────────────────┘

┌ 欧冠 2026 ───────────────────────┐
│ 欧洲 · 俱乐部杯赛                 │
│ 冠军、晋级决赛和两回合系列赛预测   │
│ 冠军 / 晋级决赛 / 两回合系列赛      │
│ 3 个预测                           │
└──────────────────────────────────┘

┌ 英超 2025/26 ────────────────────┐
│ 英格兰 · 联赛赛季                 │
│ 冠军、前四和降级预测               │
│ 冠军 / 欧冠资格 / 降级             │
│ 3 个预测                           │
└──────────────────────────────────┘
```

### 3.3 系列赛详情页

### 3.4 为什么不使用全局阶段导航

全局阶段导航会把不同对象的维度混在一起。例如世界杯有小组赛、16 强、8 强；英超没有淘汰赛，只有冠军、欧冠资格、降级；欧冠有两回合系列赛但不一定有小组出线。
因此阶段导航必须绑定在具体对象内部，而不是放在“冠军与晋级”的全局顶部。

## 四、当前 mock 覆盖

### 4.1 系列赛 / 赛季对象

| 对象 | 类型 | 阶段 | 当前预测 |
|------|------|------|----------|
| 世界杯 2026 | 杯赛系列赛 | 小组赛至决赛 | A组第一、A组出线、进入8强、进入决赛、世界杯冠军 |
| 欧冠 2026 | 俱乐部杯赛 | 淘汰赛 | 欧冠冠军、晋级决赛、两回合系列赛赛果 |
| 英超 2025/26 | 联赛赛季 | 赛季进行中 | 英超冠军、获得欧冠资格、降级球队 |

### 4.2 市场类型

| 分组 | 适用对象 | 示例 | 选项形态 |
|------|----------|------|----------|
| 小组赛 | 世界杯、杯赛 | A组第一、A组出线 | 多选一或球队 是/否 |
| 淘汰赛 | 世界杯、欧冠 | 进入8强、进入决赛、晋级决赛 | 球队 是/否 |
| 冠军 | 杯赛、联赛 | 世界杯冠军、欧冠冠军、英超冠军 | 多球队按钮 |
| 晋级 | 杯赛、资格 | 晋级决赛、获得欧冠资格 | 球队 是/否 |
| 赛季结果 | 联赛 | 降级球队、前四、前六 | 多球队按钮或 是/否 |
| 系列赛 | 两回合淘汰赛 | 两回合系列赛赛果 | 晋级方 / 特殊结果 |

### 4.3 命名规则

- “冠军与晋级”是一级产品入口，不叫“预测市场”，避免误导为 CLOB。
- “单场预测”承载近期单场比赛结果和比赛内容。
- “系列赛对象”可以是世界杯、欧冠、英超赛季等，不等于两回合系列赛盘口。
- “系列赛”作为盘口分组时，特指两回合或阶段性对抗的最终赛果。
- “出线”“进入8强”“进入决赛”“晋级决赛”“获得资格”都归为晋级类市场。

## 五、用户路径

### 5.1 单场用户

```text
足球首页 → 单场预测 → 选择比赛 → 比赛详情 → 选择盘口 → 投注单 → 二次确认 → 我的注单
```

### 5.2 冠军与晋级用户

```text
足球首页 → 冠军与晋级 → 选择世界杯 2026 → 小组赛 / 淘汰赛 / 冠军 → 选择预测 → 投注单 → 二次确认 → 我的注单
```

### 5.3 欧冠系列赛用户

```text
足球首页 → 冠军与晋级 → 欧冠 2026 → 系列赛 → 两回合系列赛赛果 → 选择晋级方 → 投注单
```

## 六、投注与结算规则

v4.7 不改变 v4.4 的下注规则：

- 冠军与晋级支持单注和多笔单注。
- 冠军与晋级暂不支持串关。
- 可与单场预测的选项共存在同一个投注单中，但提交时按多笔单注生成独立注单。
- 每个市场展示关闭时间、预计结算时点和官方结算来源。
- 市场关闭条件按关闭时间、阶段开始、结果已数学确定或官方暂停处理，不按单场开赛处理。
- 报价变化、报价过期、二次确认、余额不足、盘口关闭等提交流程沿用 v4.4。

## 七、Design Board 覆盖要求

Design Board 必须覆盖以下内容：

| 覆盖项 | 要求 |
|--------|------|
| 首页 tab | 展示“单场预测 / 冠军与晋级”两个入口 |
| 冠军与晋级首页 | 展示世界杯、欧冠、英超等系列赛/赛季对象卡片 |
| 系列赛详情页 | 展示对象头部、阶段分组、市场卡片、关闭时间、结算来源 |
| 全量市场矩阵 | 从 `futuresData` 动态读取当前全部赛事级市场，当前应为 11 个 |
| 状态覆盖 | 包含 open、upcoming、暂停、封盘、官方待确认、已结算、作废等状态说明 |
| 投注单 | 说明冠军与晋级可多笔单注，不支持串关 |
| 隐藏能力 | v4.5 预测大赛仍不进入 Design Board |

## 八、验收标准

- `/soccer` 默认进入“单场预测”，可切换到“冠军与晋级”。
- `/soccer?view=futures` 只展示系列赛/赛季对象，不全局混排所有市场。
- `/soccer/futures/world-cup-2026` 内部按“小组赛 / 淘汰赛 / 冠军”展示预测。
- `/soccer/futures/ucl-2026` 内部按“冠军 / 晋级 / 系列赛”展示预测。
- `/soccer/futures/premier-league-2026` 内部按“冠军 / 赛季结果”展示预测。
- `futuresData` 的市场数量变化后，Design Board 指标和全量矩阵自动同步。
- Design Board 不展示 v4.5 预测大赛报名、填表、榜单、分享、赛后复盘等隐藏能力。
- `npm run build` 通过。
