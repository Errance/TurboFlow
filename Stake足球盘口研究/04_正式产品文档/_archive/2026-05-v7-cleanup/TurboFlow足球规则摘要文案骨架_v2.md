# TurboFlow足球规则摘要文案骨架 v2

## 1. 文档定位
- 本文用于定义 TurboFlow 足球预测市场 P0 市场的规则摘要文案骨架。
- 本文聚焦用户实际看到的规则摘要表达。
- 本文不是最终线上文案定稿。

## 2. 文案原则
- 简短
- 普通用户可理解
- 不堆 sportsbook 术语
- 首屏只写必须知道的边界
- 复杂异常与规则差异放在展开说明

## 3. 哪些规则必须首屏显示
- 常规时间结算
- 含补时
- 不含加时
- 比赛中断 / 延期后的 `48h` 继续规则
- 超过 `48h` 未恢复的未决问题作废
- 上半场市场按法定 `45` 分钟加补时解释

## 4. 哪些规则只应放在展开说明
- 错误比分取消逻辑的更完整解释
- `Double Chance` 的合并语义解释
- `void / cancelled / corrected` 的差异解释
- 中断恢复后的更细状态路径
- 非首期市场的特例规则

## 5. P0 市场首屏规则摘要建议

### `1x2`
- `按90分钟比赛结果结算，含补时，不含加时。`
- `比赛中断后48小时内恢复则继续结算，超时未决作废。`

### `主队不败 / 客队不败 / 两队不会打平`
- `按常规时间结算，含补时，不含加时。`
- `这是主结果问题的补充表达。`

### `全场总进球高于/低于`
- `按全场总进球结算，含补时，不含加时。`
- `比赛中断后按48小时规则处理。`

### `上半场结果市场`
- `只按上半场法定45分钟加补时结算。`
- `不延伸到下半场结果。`

### `上半场总进球高于/低于`
- `只按上半场法定45分钟加补时结算。`
- `按上半场时间窗口内总进球判断。`

## 6. P0 市场展开规则摘要建议

### `1x2`
- `本问题按90分钟比赛结果结算。`
- `伤停补时计入结果，加时赛不计入。`
- `若比赛中断，48小时内恢复则按最终结果继续结算；超时未恢复的未决问题作废。`
- `错误比分显示期间，相关问题可能取消。`

### `主队不败 / 客队不败 / 两队不会打平`
- `这三类问题来自同一底层结果能力。`
- `前台使用普通用户表达。`
- `时间范围与中断处理沿用主赛果规则。`

### `全场总进球高于/低于`
- `本问题按全场总进球结算。`
- `伤停补时计入，加时赛不计入。`
- `X.5 为首期阈值表达位。`
- `若比赛中断，按48小时规则继续处理或作废。`

### `上半场结果市场`
- `本问题只看上半场法定45分钟与补时。`
- `下半场结果不影响本问题结算。`
- `若比赛在对应结算前发生异常，按通用规则处理。`

### `上半场总进球高于/低于`
- `本问题只看上半场法定45分钟与补时内的总进球。`
- `若比赛异常中断，按通用中断与48小时规则处理。`

## 7. 各 P0 市场覆盖范围
- `1x2`
- `主队不败 / 客队不败 / 两队不会打平`
- `全场总进球高于/低于`
- `上半场结果市场`
- `上半场总进球高于/低于`

## 8. 使用边界
- 本文案骨架用于产品与设计协作
- 若后续需要更细的错误提示、异常提示、结果提示，可在不改变本版规则边界的前提下继续细化
- `上半场总进球高于/低于` 的证据属性继续以主 PRD、范围定义和模型层为准
